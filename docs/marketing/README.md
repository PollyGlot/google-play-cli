# gplay — Marketing

Public-facing positioning material for `gplay`. Deliberately sparse:
the only artifact that belongs in the repo is the positioning manifesto
itself. Tactical content (launch copy, post templates, editorial
planning) lives outside the repo so it can be iterated freely without
turning into a public commitment.

## Files

| File | What it is |
|---|---|
| [POSITIONING.md](POSITIONING.md) | The manifesto. One-liner, pillars, audiences, vision, voice, the "historical accident" framing that motivates the project. Source of truth for any public copy about gplay. |

## Maintenance rule

When positioning shifts (new pillar, new audience, dropped feature),
update [POSITIONING.md](POSITIONING.md) first. Any downstream copy —
README, social posts, talk pitches, skill descriptions — must remain
consistent with the manifesto.
